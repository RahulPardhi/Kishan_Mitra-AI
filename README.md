# Kishan Mitra AI

Kisan Mitra AI is an AI-powered smart farming assistant designed to help farmers make better agricultural decisions. It provides real-time weather information, AI chatbot assistance, crop disease detection, soil analysis, multilingual support, and voice interaction through a modern, responsive interface.

---

## 🚀 Features

- 🔐 User Authentication (Register & Login)
- 👤 User Profile Management
- 🌦️ Real-Time Weather Forecast
- 🌱 Soil Analysis
- 🌿 AI Crop Disease Detection
- 🤖 AI Farming Chatbot
- 🎤 Voice Assistant
- 🌐 Multi-Language Support (English, Hindi, Marathi)
- 🌙 Dark Mode
- 📱 Responsive UI
- ⚡ Modern Dashboard
